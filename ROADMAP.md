# Roadmap

Planned work for VocabuLab, roughly in order. Hour estimates are rough.

## Release

- [ ] Register a separate iOS app in AdMob and use its own app ID (iOS currently reuses the Android ID). _~1 h_
- [ ] First iOS build on a real device and fixes for anything iOS-specific. _~4 h_
- [ ] Prepare store listings, screenshots and privacy labels for Google Play and the App Store. _~6 h_

## Lex and the lab

- [ ] Animate Lex properly: a real walk cycle between furniture, sitting, leaning and lying poses (Rive or an SVG rig). _~12 h_
- [ ] Moving furniture: burner flame, bubbling flasks, steam and clock hand inside the app (today they only move in the design mockups). _~4 h_
- [ ] Lex outfits: recolorable lab coats and accessories, shown on Lex and sold in the shop. _~8 h_
- [ ] Item rarities (Common to Legendary) that change an item's colors and finish, with an "Animated / Still" tag kept separate. _~6 h_
- [ ] Topic trophies: finishing a topic unlocks its own lab item. _~8 h_
- [ ] Bigger homes: two-floor and themed homes, with Lex using the stairs. _~16 h_
- [ ] Translate the new lab texts into all supported languages. _~3 h_

## Learning

- [ ] Redesign the ad-free pass screen around what it really offers (no token limits, lab perks). _~4 h_
- [ ] Review reminders through local notifications. _~4 h_
- [ ] Audio pronunciation for more languages. _~6 h_

## Quality

- [ ] Fix the web export (it currently fails on the ads SDK) so the app can be previewed in a browser. _~3 h_
- [ ] More component tests for the review session, decks and arrange mode. _~6 h_
- [ ] Clean up remaining ESLint warnings. _~3 h_
